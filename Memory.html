Chapter 01

The Memory Core

At the heart of every intelligent AI system lies a memory architecture — a set of interconnected layers that store, retrieve, and reason over information.

Chapter 02

Context Window

The innermost layer — a fixed-size buffer of 128K tokens where all reasoning happens. System prompts, retrieved context, history, and tool results all compete for precious space.

Chapter 03

Vector Store (RAG)

Expanding beyond the core — vector embeddings scattered across a database, retrieved by cosine similarity. This is the AI's long-term semantic memory, billions of documents at your fingertips.

Chapter 04

Knowledge Graph

Structured relationships between entities — a web of connections that enable reasoning, inference, and understanding of how concepts, users, and tasks relate to each other.

Chapter 05

Episodic Memory

Temporal flow and session history — remembering specific interactions, user preferences, and decisions across time. Building a persistent model of who you're working with.

Chapter 06

Reflection

The outermost layer — meta-cognition. The system observes its own performance, evaluates outcomes, and adapts. Self-improvement through introspection and feedback loops.

Layer 01

Context Window Management

Priority-based token allocation. System prompts first, then retrieved context, then conversation history. Dynamic assembly based on query intent.

Layer 02

Retrieval-Augmented Generation

Documents chunked, embedded, and stored. At query time, the most semantically similar chunks are retrieved with cosine similarity and fed into the context window.

Layer 03

Episodic Memory

Stores the sequence of interactions across sessions. Remembers your preferences, past decisions, and conversation history — building a persistent user model.
